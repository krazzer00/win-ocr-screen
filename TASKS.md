# План улучшений

- **Конфигурация путей**: использовать настройки или переменные окружения вместо жёстко заданных путей к `python.exe` и `tesseract.exe` в скриптах.
- **Временные файлы**: сохранять скриншоты во временную директорию либо передавать данные напрямую в память.
- **Обработка ошибок**: добавить логирование и сообщения об ошибках (например, отсутствие Tesseract).
- **Зависимости**: проверить необходимость `pyautogui` и убрать его из `requirements.txt`, добавить файл `.gitignore` для временных файлов.
- **Асинхронность**: выполнять OCR в отдельном потоке, чтобы интерфейс не зависал.
- **Кроссплатформенность**: добавить сборку и пакеты для Linux и macOS.
- **Системный трей**: реализовать значок для управления приложением и доступом к настройкам.
- **Настройки**: отдельный диалог с выбором языков OCR, горячих клавиш и путей к зависимостям.
- **История**: сохранять снимки и позволять повторно запускать распознавание.
- **Перевод**: опционально интегрировать перевод распознанного текста при доступе к сети.
