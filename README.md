# Win OCR Screen

![python](https://img.shields.io/badge/python-3.10%2B-blue)
![PyQt5](https://img.shields.io/badge/PyQt5-%F0%9F%92%96-green)

**Win OCR Screen** — небольшая утилита для создания снимков экрана и мгновенного оптического распознавания текста.

![screenshot](screenshot.png)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск


```bash
python gui_app.py
```

При первом запуске при отсутствии установленного Tesseract программа
автоматически скачает переносимую версию в каталог `app_data`. При
необходимости можно указать путь к своей копии Tesseract через переменную
`TESSERACT_PATH` и интерпретатор Python через `PYTHON_EXECUTABLE`.

Для быстрого запуска можно основаться на скриптах `ocr.sh` и `ocr.bat`. На
Windows также доступен файл `auto_build_and_run.bat`, который загрузит
переносимый Python, соберёт приложение в `gui_app.exe` и запустит его.

Приложение сворачивается в системный трей и может управляться через значок, где
доступны команды захвата экрана, открытия настроек и выхода. В диалоге настроек
можно изменить языки распознавания и путь к Tesseract.

### Переменные окружения

- `TESSERACT_PATH` — путь к исполняемому файлу Tesseract (если не нужен
  автоматический скачивание).
- `PYTHON_EXECUTABLE` — альтернативный интерпретатор Python для скриптов
  `ocr.sh` и `ocr.bat`.
- `OCR_LANGS` — языки распознавания в формате Tesseract (по умолчанию
  `rus+eng`). Значение можно задавать также через диалог настроек.
- `TRANSLATE_TO` — код языка для автоматического перевода распознанного текста.

## Горячие клавиши

- `Ctrl+Alt+O` — пуск или остановка программы.
- `Ctrl+Alt+P` — выход.

## Файлы

- `gui_app.py` — основное приложение с графическим интерфейсом и поддержкой горячих клавиш.
- `ocr_screen.py` — модуль выбора области экрана и передачи изображения в Tesseract.
- `starter.py` — пример запуска только через горячие клавиши.
- `ocr.sh` и `ocr.bat` — примеры скриптов для запуска.
- `requirements.txt` — зависимости Python.

## Сборка `.exe`

Для создания автономного исполняемого файла под Windows можно использовать `PyInstaller`:

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile gui_app.py
```

После сборки файл появится в каталоге `dist/`. Такой `.exe` можно запускать без установленного Python. При первом запуске программа создаст папку `app_data` рядом с `exe` и автоматически загрузит портативный пакет Tesseract. Отдельный дисплей для сборки не требуется, достаточно выполнить команды выше в консоли.

### Сборка под Linux и macOS

Для Linux и macOS используется тот же `PyInstaller`:

```bash
pyinstaller --onefile gui_app.py
```

В macOS при необходимости добавьте флаг `--windowed`, чтобы скрыть консоль при запуске.

## Автоматическая сборка и запуск

Для пользователей Windows добавлен скрипт `auto_build_and_run.bat`. Он не требует
предварительно установленного Python или Tesseract. При первом запуске скрипт
скачает переносимую версию Python в подкаталог `python`, установит все
зависимости, предварительно загрузит портативный Tesseract, соберёт файл
`gui_app.exe` в текущем каталоге и сразу его запустит. Достаточно распаковать
архив и запустить этот файл.
